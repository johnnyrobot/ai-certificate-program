# AI Infrastructure Certificate Curriculum Site — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a public, static, multi-page curriculum website for the LACCD non-credit "AI Infrastructure and Architecture" certificate (AIINFRA 100–303), styled as a sibling of johnnyphung.com, with a live LMI/BLS careers dashboard.

**Architecture:** Static site in `site/` (no build step, directly servable). Content and LMI data are generated into `site/data/*.json` by Python scripts in `build/`; `build/render_site.py` deterministically templates `index.html` + 10 course pages from that data. Client-side `site/app.js` adds dashboard interactivity and a progressive-enhancement live refresh from California's open-data portal (CORS-open, keyless). BLS national context is baked server-side (key never shipped to the browser).

**Tech Stack:** HTML5, CSS custom properties (design system ported verbatim from johnnyphung.com), vanilla JS (ES2020 `fetch`), Python 3 stdlib (`json`, `csv`, `urllib`, `datetime`), Notion MCP (content extraction), python `http.server` + Claude preview MCP (verification). No frameworks, no bundler, no runtime deps. Google Fonts CSS is the only external asset (matches reference).

## Global Constraints

- **Light mode only** — no dark-mode styles, no `prefers-color-scheme` color overrides.
- **Design tokens verbatim** from johnnyphung.com `:root` (see Task 1). Accent `#4F46E5`; gradient `linear-gradient(100deg,#4F46E5,#6366F1 55%,#8B5CF6)`; Inter + JetBrains Mono.
- **No build step for `site/`** — every file under `site/` is a servable static asset.
- **BLS API key never in client code.** `build/refresh_lmi.py` reads it from `os.environ['BLS_API_KEY']` only. Not committed. (Key is recorded in project memory; export before running.)
- **Only the 8 verified SOC occupations** may appear; each course's `socs` ⊆ `{15-2051, 15-1221, 15-1252, 11-3021, 15-1241, 15-1299, 15-1211, 15-1244}`.
- **Baked LMI headline figures must equal the Phase-1 report exactly** (test-enforced): median wage, growth %, openings per SOC (see `VERIFIED` table in Task 3).
- **WCAG 2.2 AA** — semantic headings, `:focus-visible` rings, table semantics (`<th scope>`, `<caption>`), color-independent meaning, `prefers-reduced-motion` honored.
- **Data provenance visible** — `asOf` labels, source citations, and the live-badge state on the dashboard.
- Program facts (verbatim): 10 courses · 540 contact hours · 30-unit credit-equivalent · 3 semesters · 54 contact hours/course · 16 weeks/course. Sem 1 = 100/101/102 (162h); Sem 2 = 200/201/202 (162h); Sem 3 = 300/301/302/303 (216h).

- [ ] **Step 4: Write `build/merge_curriculum.py`**

Assembles the raw per-course files + program-level prose into the final `curriculum.json`. Program prose (`overview`, `pathway`, `careersNarrative`) is transcribed from `AIINFRA_Modernization_Report_Phase1.md` §5/§4 (keep ≤3 short paragraphs each). Week `summary` is synthesized: a single sentence per week derived from the week title + local briefs (`scratchpad/briefs*.json`, `new_courses.json`) — factual, ≤160 chars, no invented specifics. Static fields baked in this script: `semester`, `hours=54`, `unitEquivalent=3`, `prereq`, `next` (from the canonical chain — prereq is the previous course or "none" for 100), `midtermWeek=8`, `capstoneWeek=16`, `socs` (from the §8 course→SOC map below).

```python
# build/merge_curriculum.py  (skeleton — fill program prose + week summaries)
import json, pathlib
ORDER = ["100","101","102","200","201","202","300","301","302","303"]
SEM = {**{c:1 for c in ORDER[:3]}, **{c:2 for c in ORDER[3:6]}, **{c:3 for c in ORDER[6:]}}
SOCS = {  # from spec §8 — only the 8 verified SOCs
 "100":["15-1299","15-1252"], "101":["15-1252","15-1299"], "102":["15-1241","15-1244","15-1252"],
 "200":["15-1252","15-1299","11-3021"], "201":["15-1252","15-1299"], "202":["15-2051","15-1299"],
 "300":["15-1252","15-1299"], "301":["15-2051","15-1299"], "302":["15-1299","15-1252"],
 "303":["15-1252","15-2051","11-3021"]}
def prereq(code):
    return "none" if code == "100" else f"AIINFRA {ORDER[ORDER.index(code)-1]}"
def nxt(code):
    i = ORDER.index(code); return ORDER[i+1] if i+1 < len(ORDER) else None
raw = {c: json.loads(pathlib.Path(f"site/data/_raw/{c}.json").read_text()) for c in ORDER}
courses = []
for c in ORDER:
    r = raw[c]
    courses.append({
        "code": c, "title": r["title"], "subtitle": r["subtitle"], "semester": SEM[c],
        "hours": 54, "unitEquivalent": 3, "prereq": prereq(c), "next": nxt(c),
        "description": r["description"], "objectives": r["objectives"], "slos": r["slos"],
        "weeks": r["weeks"],            # [{n,title,summary}] — summaries added in Step 3/here
        "midtermWeek": 8, "capstoneWeek": 16,
        "tools": r["tools"], "socs": SOCS[c],
    })
program = {
  "name":"AI Infrastructure and Architecture",
```

```javascript
(() => {
  "use strict";
  const CKAN = "https://data.ca.gov/api/3/action/datastore_search_sql";
  const PROJ = "274e273c-d18c-4d84-b8df-49b4d13c14ce";
  const table = document.getElementById("lmi-table");
  const usd = n => "$" + Math.round(n).toLocaleString("en-US");
  const pct = n => (n >= 0 ? "+" : "") + Number(n).toFixed(1) + "%";
  if (!table) return;
  const tbody = table.tBodies[0];
  const pairs = () => [...tbody.querySelectorAll("tr.lmi-row")].map(r => [r, r.nextElementSibling]);

  // ---- expand/collapse wage band ----
  tbody.addEventListener("click", e => {
    const row = e.target.closest("tr.lmi-row"); if (!row) return;
    row.nextElementSibling.classList.toggle("open");
  });

  // ---- sort ----
  let sortKey = null, sortDir = 1;
  table.querySelectorAll("th[data-sort]").forEach(th => th.addEventListener("click", () => {
    const k = th.dataset.sort;
    sortDir = sortKey === k ? -sortDir : 1; sortKey = k;
    const val = r => k === "occ" ? r.querySelector(".occ").textContent.toLowerCase()
                                 : parseFloat(r.dataset[k === "median" ? "median" : k]);
    pairs().sort((a, b) => (val(a[0]) > val(b[0]) ? 1 : -1) * sortDir)
           .forEach(([r, band]) => { tbody.appendChild(r); tbody.appendChild(band); });
  }));

  // ---- filter by semester / course (options injected from window.__COURSES if present) ----
  const selSem = document.getElementById("lmi-filter-sem");
  const selCourse = document.getElementById("lmi-filter-course");
  function applyFilter() {
    const socsFor = selCourse && selCourse.value ? selCourse.value.split(",") : null;
    pairs().forEach(([r, band]) => {
      const show = !socsFor || socsFor.includes(r.dataset.soc);
      r.style.display = show ? "" : "none";
      band.style.display = show ? "" : "none";
      if (!show) band.classList.remove("open");
    });
  }
  selSem && selSem.addEventListener("change", applyFilter);
  selCourse && selCourse.addEventListener("change", applyFilter);

  // ---- live refresh from data.ca.gov (progressive enhancement) ----
  function setBadge(state, label) {
    const b = document.getElementById("lmi-badge");
    if (!b) return; b.dataset.state = state; b.textContent = label;
  }
  async function liveRefresh() {
    const rows = [...tbody.querySelectorAll("tr.lmi-row")];
    const socs = rows.map(r => r.dataset.soc);
    const inList = socs.map(s => `'${s}'`).join(",");
    const sql = `SELECT "Standard Occupational Classification (SOC)" soc,"Percentage Change" growth,` +
      `"Total Job Openings" openings,"Median Annual Wage" median FROM "${PROJ}" ` +
      `WHERE "Area Name"='California' AND "Period"='2024-2034' AND ` +
      `"Standard Occupational Classification (SOC)" IN (${inList})`;
    const ctrl = new AbortController(); const to = setTimeout(() => ctrl.abort(), 8000);
    const res = await fetch(CKAN + "?sql=" + encodeURIComponent(sql), { signal: ctrl.signal, headers: { Accept: "application/json" } });
    clearTimeout(to);
    const j = await res.json(); if (!j.success) throw new Error("ckan");
    const by = {}; j.result.records.forEach(r => by[r.soc] = r);
    let n = 0, period = "";
    rows.forEach(r => {
      const rec = by[r.dataset.soc]; if (!rec) return;
      const med = parseFloat(String(rec.median).replace(/[,$]/g, ""));
      const gr = parseFloat(rec.growth), op = parseInt(String(rec.openings).replace(/,/g, ""), 10);
      if (med) { r.dataset.median = med; r.querySelector(".median").textContent = usd(med); }
      if (!isNaN(gr)) { r.dataset.growth = gr; const g = r.querySelector(".growth"); g.textContent = pct(gr); g.className = "num growth " + (gr >= 0 ? "up" : "down"); }
      if (!isNaN(op)) { r.dataset.openings = op; r.querySelector(".openings").textContent = op.toLocaleString("en-US"); }
      n++;
    });
    if (n) setBadge("live", `● live · updated ${new Date().toLocaleDateString("en-US")} · data.ca.gov`);
  }

  // ---- init ----
  document.addEventListener("DOMContentLoaded", () => {
    // populate course filter from a global the page may define
    if (selCourse && window.__COURSES) window.__COURSES.forEach(c => {
      const o = document.createElement("option"); o.value = c.socs.join(","); o.textContent = `${c.code} — ${c.title}`; selCourse.appendChild(o);
    });
    liveRefresh().catch(() => setBadge("snapshot", document.getElementById("lmi-badge").textContent));
  });
})();
```
